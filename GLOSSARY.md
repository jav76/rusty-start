# Glossary

- **Fog Veil**: The full-monitor (`rcMonitor`, including the taskbar) progressive backdrop blur and atmospheric dim layer surrounding the floating Start menu card while the menu is open.
  - _Avoid_: modal overlay, dimmer, wallpaper blur.
- **Liquid-Glass Card**: The `640x720` floating Start menu surface rendered via an SDF rounded-rectangle fragment shader with curved-bevel lens refraction, subtle chromatic dispersion, deep interior frost, and fresnel specular highlights.
  - _Avoid_: acrylic box, modal dialog, popup panel.
- **Optical Condense**: The `180ms` open transition that pairs subtle card scale (`0.92 -> 1.0`) and vertical lift (`16px -> 0px`) with a transient lens-refraction pulse and a diagonal specular rim sweep while keyboard focus is active immediately at `t = 0ms`.
  - _Avoid_: fade-in, zoom animation.
- **Pinned Apps**: Apps the user pinned (Ctrl+P or the row's pin button), listed first in pin order whenever the search is empty.
  - _Avoid_: favorites, bookmarks.
- **Recent Apps**: Up to five most recently launched apps that are not pinned, listed between the Pinned Apps and All apps.
  - _Avoid_: history, MRU list.
- **Frecency**: Launch count weighted by how recently the app was last launched. Breaks ties between search results of the same match quality.
  - _Avoid_: popularity, usage score.
- **Power Flyout**: The panel above the card's power button listing Lock, Sign out, Sleep, Restart and Shut down.
  - _Avoid_: shutdown menu, power menu.
- **App Action Flyout**: The panel opened from an app row (right-click, the Menu key or Shift+F10) listing what else can be done with that app, such as Open file location, Run as administrator or the app's own desktop actions.
  - _Avoid_: context menu, jump list, right-click menu.
- **Web Fallback**: The opt-in last search row, below every other result, that opens the query in the user's chosen search engine. Nothing is sent anywhere unless that row is chosen.
  - _Avoid_: web results, web suggestions, Bing search.
- **Card Anchor**: One of nine alignment presets, chosen on a 3x3 grid (`top-left` through `bottom-right`, `middle-left` by default), that determines where the `640x720` Liquid-Glass Card sits within the active monitor's Fog Veil.
  - _Avoid_: window dock, screen gravity.
- **Veil Mode**: How the area around the Liquid-Glass Card is drawn: the full Fog Veil (blurred and dimmed), Dim (the live desktop dimmed without blur) or Off (the card alone).
  - _Avoid_: backdrop mode, blur toggle.
- **Settings Page**: The view inside the Liquid-Glass Card, opened with the gear button or Ctrl+,, that replaces the app list with the card position, Veil Mode, blur strength, Meta key switch and Setup Audit.
  - _Avoid_: settings window, preferences dialog.
- **Setup Audit**: The per-item report of the desktop integration `rusty-start setup` manages (Meta key binding, KWin window rule, autostart), each installed, missing or in conflict, plus read-only hook status on Windows.
  - _Avoid_: health check, diagnostics.
- **Launch ID**: The platform identifier the host uses to launch an app and to key its pins and launch history: an AppUserModelID or known-folder path on Windows, a desktop file ID (`org.kde.konsole.desktop`) on Linux.
  - _Avoid_: app path, exe name, app ID.
- **Plain Glass**: The Fog Veil and Liquid-Glass Card drawn without a desktop snapshot: a dimmed veil and a frosted, unrefracted card over the live desktop. Used when capture is refused, unavailable or takes longer than 100 ms.
  - _Avoid_: fallback mode, no-blur mode.
