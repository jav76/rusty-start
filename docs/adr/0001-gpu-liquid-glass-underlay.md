# 0001: Pre-Show GDI Snapshot and OpenGL Underlay for Liquid-Glass Rendering

When the Start menu opens, `rusty-start` captures the active cursor monitor (`rcMonitor`) via a pre-allocated GDI `CreateDIBSection` and `BitBlt` before showing the window, uploads the pixels into a 3-pass GPU dual-Kawase mip pyramid, and renders both the outer Fog Veil and the `640x720` Liquid-Glass Card in a custom `glow` fragment shader during Slint's `RenderingState::BeforeRendering` pass. Native Windows DWM Acrylic (`DwmSetWindowAttribute` / `SetWindowCompositionAttribute`) was rejected because DWM cannot animate its blur radius from zero, cannot perform SDF bevel lens refraction or chromatic dispersion on desktop pixels, and cannot apply distinct blur depths to the outer screen veil and inner card within a single HWND. `IDXGIOutputDuplication` was rejected because it fails with `DXGI_ERROR_NOT_CURRENTLY_AVAILABLE` whenever a screen recorder (such as OBS or Discord) holds the output duplication lock, whereas a pre-allocated GDI `BitBlt` succeeds reliably in ~1-2 ms without hiding the Start menu from screenshots (`WDA_EXCLUDEFROMCAPTURE`).
